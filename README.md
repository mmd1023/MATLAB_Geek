# 🧑‍💻 MATLAB Geek Bootcamp

> **Learn MATLAB by solving real problems, not by memorizing commands.**

**MATLAB Geek Bootcamp** is a hands-on course built to teach MATLAB from the ground up and gradually take you toward engineering computation and simulation.

I'm **mmd**, the instructor of the course, and the bootcamp is organized by **ElectroGeek** ⚡

While the main goal is learning MATLAB, the examples are designed with an **engineering flavor** — especially circuits and Electrical Engineering. Instead of isolated textbook exercises, we try to connect MATLAB concepts to problems inspired by the real world, making the code easier to understand, remember, and actually use.

---

## 📚 Course Roadmap

### Week 0 — MATLAB Fundamentals

* MATLAB environment, Command Window & Workspace
* Variables and data types
* Vectors, matrices & indexing
* Operators and matrix functions
* Common MATLAB functions
* User input & comments
* Engineering examples with circuits

### Week 1 — Programming Fundamentals

* `if / else`
* `for` & `while`
* Debugging & breakpoints
* Mathematical and trigonometric functions
* Complex numbers
* Random numbers
* Numerical problem solving

### Week 2 — Data Visualization

* 2D & 3D plots
* `plot`, `bar`, `histogram`, `scatter`, `pie`
* `subplot` & `hold on`
* `mesh` & `surf`
* Plot customization
* Engineering and real-world data visualization

### Week 3 — Functions & File Handling

* Scripts & functions
* Reusable MATLAB code
* TXT, CSV & Excel files
* Working with external data

### Week 4 — Symbolic Mathematics

* Symbolic variables & expressions
* Equation systems
* Derivatives & Jacobians
* Integrals
* Laplace transforms
* Differential equations

### Week 5 — Simulink & Circuit Simulation

* Simulink fundamentals
* Simscape
* RC & RLC circuits
* Step and AC inputs
* Simulation data & MATLAB Workspace
* Phasor analysis and RMS voltage
